# dsh-plugin-dir-sync

DSH 目录定时同步插件：按 cron 表达式把「源目录」整个复制到「目标目录」，逐条规则可单独开关，侧边栏底部重启按钮的左边还有一键「立即同步」。

## 功能

- **规则对**：每条规则由源目录、目标目录、同步间隔（cron）三部分组成，最多 30 条。
- **逐条开关**：每条规则旁边的开关控制是否参与定时同步；开着开关改动其它字段时需要点「保存规则」才生效，只拨开关会自动保存。
- **定时复制**：到点后把源目录里的内容整个复制进目标目录，子目录结构保持一致。
- **增量**：大小和修改时间都没变的文件会跳过；复制完成后回写目标文件的修改时间，让下一次依旧可以跳过。
- **镜像（可选）**：勾选「镜像」后，目标目录里多出来的文件/目录会被删除，让目标与源完全一致。镜像只在本次复制没有任何错误时执行删除，出错时保持目标不动。
- **立即同步**：侧边栏底部的同步按钮会同步所有已开启的规则，完成后弹窗列出每条规则的结果；没有已开启的规则时会给出提示。

## 配置界面

在「插件」页里找到「目录同步」，进入插件详情页后点「包含的组件」里「目录同步」这一行（后面带 `>`）打开配置页：

- 工具栏：保存规则 / 添加规则 / 放弃修改，右侧显示 `n/30 条` 和未保存状态。
- 每条规则卡片：开关、状态文字（上次手动/定时同步时间、文件数、体积、跳过与删除数量，或失败原因）、源目录、目标目录、同步间隔、镜像开关、删除。
- 同步间隔输入框带常用表达式下拉提示（`0 3 * * *`、`*/30 * * * *` 等）。
- 保存时校验：路径必须是绝对路径、源和目标不能相同或互相嵌套、不能使用盘符根目录、cron 必须合法；不通过时逐条返回问题，不会覆盖已保存的规则。

## cron 语法

标准 5 段式：`分 时 日 月 周`。

| 写法 | 含义 |
| --- | --- |
| `0 3 * * *` | 每天 03:00 |
| `*/30 * * * *` | 每 30 分钟 |
| `0 9 * * 1-5` | 工作日 09:00 |
| `0 0 1 * *` | 每月 1 号 00:00 |
| `0 0 * * 0` | 每周日 00:00 |

支持 `*`、单值、区间 `a-b`、步进 `*/n` 与 `a/n`、逗号列表，月份可写 `JAN-DEC`、星期可写 `SUN-SAT`（`7` 等同周日）；也支持 `@hourly`、`@daily`、`@midnight`、`@weekly`、`@monthly`、`@yearly`、`@annually` 别名。日和周同时受限时按「满足其一」匹配。

## 数据与实现

- 规则保存在 `%DSH_HOME%\plugin-data\dsh-plugin-dir-sync\rules.json`（默认 `C:\Users\<用户>\.dsh\plugin-data\...`），原子写入；文件损坏时会重命名为 `rules.json.broken-<时间戳>` 后从空表启动。
- Host 侧每秒检查一次当前分钟，命中规则即执行；同一分钟不会重复触发，单条规则不会并发执行。
- 复制跳过符号链接与目录联接；源目录不存在时只提示、不中断其它规则。
- Host 路由（均由查询页面驱动）：
  - `GET /plugins-local/dsh-dir-sync/state`
  - `POST /plugins-local/dsh-dir-sync/save`
  - `POST /plugins-local/dsh-dir-sync/toggle`
  - `POST /plugins-local/dsh-dir-sync/run`
  - `POST /plugins-local/dsh-dir-sync/status`

## 安装

在 DSH 的「插件」页从本地安装，或由插件管理器安装本目录：

```
dsh-plugin-dir-sync/
├── index.js            # Host：cron 解析、规则校验、复制引擎、调度、路由
├── client.js           # 浏览器：配置页 + 侧边栏「立即同步」按钮
├── cordis.patch.yml    # 激活补丁
├── locale/{zh,en}.json # 插件市场展示文案
└── icon.svg
```

安装后需要重启 DSH（侧边栏底部设置按钮旁的「重启」），新版本才会加载。
